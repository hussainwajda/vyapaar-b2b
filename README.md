# Vyapaar B2B Platform

## Overview
Vyapaar is a cloud-powered B2B e-commerce platform connecting manufacturers, wholesalers, and retailers.

## Features
- Product Management
- Bulk Ordering
- Buyer-Seller Communication
- Authentication & Authorization
- Cloud Integration

## Technology Stack
- React.js
- Node.js
- Express.js
- MongoDB
- AWS

## Future Enhancements
- Payment Gateway Integration
- Real-time Notifications
- AI-based Product Recommendations
